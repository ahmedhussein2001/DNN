# 🧠 Deep Neural Network (DNN) from Scratch

## 📍 Overview
This project demonstrates the implementation of a Deep Neural Network (DNN) from scratch using only **NumPy**, without any high-level deep learning frameworks (like TensorFlow or PyTorch). It shows a full pipeline from forward propagation, loss calculation, backpropagation, to model training and evaluation.

## 🧠 Objectives
- Build a multi-layer neural network using Python & NumPy.
- Understand the internals of forward and backward propagation.
- Train the model to perform binary or multi-class classification.
- Visualize training performance using loss and accuracy metrics.

## 🛠️ Technologies Used
- **Python**
- **NumPy** – Core math operations & array handling
- **Matplotlib** – For visualizing loss/accuracy trends
- **Jupyter Notebook**

## 🔍 Workflow
1. **Data Preparation** – Use synthetic or imported dataset.
2. **Network Architecture** – User-defined layer sizes and activation functions.
3. **Forward Propagation** – Linear transformations + activations.
4. **Loss Calculation** – Cross-entropy or MSE.
5. **Backpropagation** – Compute gradients manually.
6. **Model Training** – Gradient descent with learning rate tuning.
7. **Evaluation** – Accuracy & loss plots.
